# Portfolio | Shahram

A modern, responsive portfolio built to showcase my journey as a **Frontend Developer**. This project emphasizes clean UI/UX, performant React patterns, and a type-safe architecture.

---

## 🚀 Tech Stack

- **Framework:** React 19
- **Language:** TypeScript
- **Styling:** Tailwind CSS (v4)
- **Icons:** React Icons
- **Deployment:** Netlify

---

## ✨ Key Features

- **Bento Grid Layout:** A sleek, structured interface for a professional look.
- **Project Gallery:** Highlighting core projects including **WorldAtlas**, **Forkity**, and **CineSeek**.
- **Dark Mode:** Fully optimized for low-light environments using Tailwind's.
- **Responsive Design:** Seamless experience across mobile, tablet, and desktop devices.
- **Type Safety:** Robust development experience with TypeScript interfaces and types.

---

## 🛠️ Installation & Setup

To get this project running locally, follow these steps:

1. **Clone the repository:**

   ```bash
   git clone [https://github.com/your-username/portfolio.git](https://github.com/your-username/portfolio.git)
   ```

2. **Navigate to the project directory:**

   ```bash
   cd portfolio
   ```

3. **Install dependencies:**

   ```bash
   npm install
   ```

4. **Install dependencies:**

   ```bash
   npm run dev
   ```

5. **Build for production:**

   ```bash
   npm run build
   ```
